# Bubdong Check-In

법동 청소년 문화센터 체크인 앱

방문 등록부터 시설 이용 신청까지, 현장 태블릿에서 처리합니다!

## 프로젝트 소개

Bubdong Check-In은 법동 청소년 문화센터에서 사용하는 방문자 체크인 앱입니다. 이 저장소는 현장 태블릿에서 실행되는 Flutter 앱을 관리합니다.

구즉 청소년 문화의 집에서 운영 중인 GuJeuk Check-In을 바탕으로, 법동 센터의 시설 구성과 운영 방식에 맞게 다시 만들었습니다. 법동은 컴퓨터·탁구·노래방처럼 자리와 인원을 관리해야 하는 시설이 있어, 방문 기록 뒤에 시설 이용 신청서를 받는 흐름이 추가되었습니다.

## 해결하려는 문제

**재방문할 때마다 반복되는 입력**
전화번호만 입력하면 기존 회원인지 확인하고, 가입된 친구는 바로 이용대장 선택으로 넘어갑니다.

**종이 대장으로 관리하던 시설 이용**
이용대장 선택과 시설 신청서를 앱에서 받아, 누가 어떤 시설을 언제부터 이용 중인지 서버에 바로 기록됩니다.

**공용 기기에 남는 개인정보**
2분 동안 화면을 만지지 않으면 처음 화면으로 돌아가, 앞사람이 입력하던 정보가 다음 사람에게 보이지 않습니다.

## 주요 기능

- 방문자 체크인: 전화번호로 회원 조회, 신규 회원 가입, 기존 회원 방문 기록
- 회원가입: 기본 정보·추가 정보 입력, 학교 검색, 개인정보 수집 동의
- 이용대장 선택: 서버에 등록된 이용대장 중 오늘 이용할 항목 선택
- 시설 신청서: 컴퓨터(좌석·사용목적), 탁구·노래방(사용 인원)
- 방명록: 오늘 방문 기록 조회, 이용대장 추가·수정 (3초 뒤 자동 저장)
- 어른 방문 기록: 회원가입·신청서 없이 이용대장만 기록
- 자동 초기화: 2분동안 입력이 없으면 홈으로 이동

## 화면 흐름

```
홈
├── 이용 대장 조회하기 → 방명록 목록 → 이용대장 수정
├── 아이들 방문 기록 남기기 → 전화번호 입력
│     ├── 기존 회원 → 이용대장 선택
│     └── 신규 회원 → 기본 정보 → 추가 정보 → 개인정보 동의 → 이
└── 어른 방문 기록 남기기 → 이용대장 선택
                                  ↓
                  시설 신청서 (필요한 시설만) → 신청 완료 → 홈
```

## 프로젝트 구조

```
lib/
├── main_bubdong.dart       # 법동 진입점
└── check_in/bubdong/
    ├── bubdong_app.dart    # 앱 설정, 자동 초기화 타이머
    ├── core/
    │   ├── component/      # 공통 위젯 (버튼, 입력칸, 카드, 화
    │   ├── network/        # API 클라이언트, 서버 오류 문구 처리
    │   └── theme/          # 색상, 글꼴, 간격, 화면 크기
    └── feature/
        ├── home/           # 홈
        ├── auth/           # 회원 조회, 회원가입, 학교 검색
        ├── facility/       # 이용대장 선택, 시설 신청서, 신청
        └── guestbook/      # 방명록 조회·수정
```

폴더 구조는 '클린 아키텍처'를 따릅니다
